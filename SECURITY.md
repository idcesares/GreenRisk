# Security policy

GreenRisk is research software and has no hosted service maintained by this
repository. For vulnerabilities that could expose credentials, execute code,
or compromise users, use GitHub private vulnerability reporting when available.
Do not publish secrets, private disclosures, or exploit payloads in an issue.

Scientific validity concerns, unexpected scores, and documentation errors are
not security vulnerabilities. Report them in a public issue with the software
version, instrument tag, input hashes or non-sensitive examples, command used,
and relevant trace/provenance output.

Only the latest repository release is supported. Model and dataset downloads
come from pinned Hugging Face revisions, but users remain responsible for
reviewing upstream artifacts and licenses in their deployment environment.
